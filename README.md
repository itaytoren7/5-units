# חמש יחידות — מרכז למידה אישי

אתר לימוד אישי לבגרות במתמטיקה 5 יח״ל, שאלונים 35581 (806) ו-35582 (807), לפי המיקוד לקיץ 2026.
האתר עובד גם בטלפון, אפשר להתקין אותו כאפליקציה (״הוספה למסך הבית״), והוא עובד גם בלי אינטרנט אחרי הטעינה הראשונה.

**כתובת האתר:** https://itaytoren7.github.io/5-units/

## מה יש באתר

- **ראשי** — ספירה לאחור לבחינה, התרגיל היומי, הודעות המאמן, התקדמות בכל שאלון, המפגשים של היום, חזרות ממתינות ונושאים חלשים.
- **שיעורים** — כל תתי-הנושאים של ספר הלימוד לשאלון 806, לפי הסדר: הסבר קצר, נקודות מפתח, תרגילים ממוקדים עם בדיקת תשובה אוטומטית, ותרגול אינסופי עם מספרים חדשים בכל פעם. נושאים שירדו במיקוד מוצגים בלי תרגילים. אפשר לסמן "למדתי בכיתה", וההמלצות, התרגיל היומי והמתכנן מתאימים את עצמם.
- **מקורות פתוחים** — תרגילים מתורגמים מ-OpenStax (CC BY-NC-SA 4.0) ושאלות בגרות ישנות של שאלון 035806 מוויקיספר (CC BY-SA 4.0), עם קרדיט על כל תרגיל.
- **סילבוס** — מפת השאלונים לפי המיקוד, סטטוס לכל תת-נושא, ודירוג שליטה אישי.
- **עמודי נושא** — תקציר, נוסחאות, דפוסי שאלות בבגרות, טעויות נפוצות, דוגמאות פתורות וכלים אינטראקטיביים.
- **תרגול** — תרגילים בסגנון בגרות עם רמזים בהדרגה, פתרון מלא והערכה עצמית לכל סעיף.
- **סימולטור** — בחינת דמה עם השעון האמיתי, התראות ב-30 וב-10 דקות, וציון לפי כללי הבחינה.
- **יומן טעויות** — עם תור חזרות מרווחות (1, 3, 7, 14 ימים).
- **בחינות עבר** — קישורים לכל בחינות הבגרות הרשמיות של 35581 ו-35582 באתר משרד החינוך (2016–2026), עם סימון "פתרתי" וציון.
- **מתכנן למידה**, **דף נוסחאות אישי** להדפסה, **הגדרות וגיבוי**.
- **מוטיבציה** — רצף ימי לימוד, עשרה תגים, וקונפטי על הצלחות (נשמר בנפרד תחת `bagrut:v1:motivation`; אפשר לכבות אנימציות בהגדרות).
- **המאמן הקשוח** — פידבק שלילי וישיר: רצף שנשבר, חזרות באיחור, ציון סימולציה נמוך או יורד, פתרון שנפתח מהר מדי בלי רמז, שלוש טעויות ברצף באותו שיעור ומפגשים שפוספסו (נשמר תחת `bagrut:v1:coach`).

כל הנתונים האישיים נשמרים בדפדפן בלבד (`localStorage`, מפתח `bagrut:v1`). מומלץ לייצא גיבוי מההגדרות.

## הפעלה מקומית

1. Node.js 20 ומעלה.
2. `npm install`
3. `npm run dev` — שרת פיתוח.
4. `npm test` — בדיקות (כולל אימות נומרי של התשובות במאגר).
5. `npm run build` — בנייה לפרודקשן.

כל דחיפה ל-`main` מריצה בדיקות ומפרסמת את האתר ל-GitHub Pages אוטומטית.

## מבנה התוכן

| תיקייה | תוכן |
|---|---|
| `src/data/syllabus/` | הסילבוס והמיקוד לכל שאלון — מקור האמת היחיד |
| `src/data/summaries/` | תקצירי נושאים, נוסחאות ודוגמאות פתורות |
| `src/data/problems/` | מאגר התרגילים ובדיקות האימות הנומריות |
| `materials/` | חומרי לימוד גולמיים לשילוב באתר |

### עדכון המיקוד
ערכו את `src/data/syllabus/35581.ts` או `35582.ts`. לכל תת-נושא יש סטטוס: `in`, `out-original` או `out-2026`.

### הוספת תרגיל
הוסיפו אובייקט `Problem` לקובץ השאלה המתאים ב-`src/data/problems/<שאלון>/`. תרגיל חדש מתחיל תמיד עם `verified: false`.
אם יש לסעיף `numericAnswer`, הוסיפו בדיקה בקובץ הבדיקות של השאלון שמחשבת את התשובה באופן עצמאי.
כל ביטוי מתמטי כתוב ב-Markdown עם `$...$`, ומחרוזות עם `\` נכתבות כ-``String.raw`...` ``.

### הוספת שאלון חדש (למשל 35571)
צרו קובץ סילבוס חדש עם הטיפוס `Questionnaire` וייצאו אותו מ-`src/data/syllabus/index.ts`. אין צורך לשנות רכיבי ממשק.

# חמש יחידות — מרכז למידה אישי

אתר לימוד אישי לבגרות במתמטיקה 5 יח״ל, שאלונים 35581 ו-35582, לפי המיקוד לקיץ 2026.

## הפעלה

1. התקנת Node.js (גרסה 20 ומעלה).
2. בתיקייה זו: `npm install`
3. הפעלה מקומית: `npm run dev`
4. בדיקות ובנייה: `npm test` ואז `npm run build`

## עדכון המיקוד

ערכו את הנתונים ב-`src/data/syllabus/35581.ts` או `35582.ts`. כל רכיב syllabus הוא נתון: מזהה נושא, כותרת ותתי-נושאים עם סטטוס `in`, `out-original` או `out-2026`. נושאים וסדר שאלות מוגדרים בקבצים האלה בלבד; רכיבי התצוגה אינם מכילים תוכן סילבוס.

הוסיפו שאלון חדש כקובץ נתונים נוסף עם הטיפוס `Questionnaire`, וייצאו אותו מתוך `src/data/syllabus/index.ts`. אין צורך לשנות את רכיבי הממשק. התאימו את בדיקות הנתונים לפני פרסום.

## מאגר תרגילים (Phase 2)

התרגילים המנוהלים נשמרים ב-`src/data/problems/index.ts`. כל בעיה כוללת שאלון, מספר שאלה, מזהה נושא, רמת קושי, סעיפים, וסטטוס `verified: false` עד שאמת/י את התשובה ידנית.

העמוד של כל נושא (`/topic/:code/:topicId`) מציג תקציר, דוגמאות עבודה ורשימת תרגילים. אם הוספתם שאלה חדשה, ודאו שהיא משויכת לנושא קיים ומחזירה בעיות עם `questionnaire`, `slot`, `topicId` ו-`subtopicIds` תקפים.

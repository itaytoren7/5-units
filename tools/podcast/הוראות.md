# יצירת פרקי הפודקאסט

התיקייה `tools/podcast` היא ערכת היצירה. היא לא עולה לאתר. יש בה:

- `make_podcast.py` – הסקריפט שיוצר את קובצי האודיו והכתוביות
- `captions.py` – מנוע הכתוביות (הסקריפט משתמש בו, לא מריצים אותו לבד)
- `podcast-script-5-units.md` – התסריט (וגם עותק PDF)
- `podcasts.html` – נגן עצמאי ישן, נשאר רק כרפרנס. הנגן של האתר נמצא בעמוד "פודקאסט"
- `הוראות.md` – הקובץ הזה

התוצרים נשמרים ישר לתיקייה שהאתר מגיש: `public/podcast/episodes`.
לכל תת-פרק נוצרים שם שני קבצים, למשל `ep-1a.mp3` ו-`ep-1a.captions.json`, ולצידם `episodes.json`
עם רשימת כל הפרקים. האתר קורא את הרשימה הזאת, ולכן פרק חדש מופיע בעמוד בלי לשנות קוד.

## 1. התקנה (פעם אחת)

1. ודאו שמותקן Python 3.9 ומעלה: בטרמינל של VS Code הריצו `python3 --version` (ב-Mac משתמשים ב-python3 וב-pip3).
2. התקינו את הספרייה של Gemini:

```
pip3 install google-genai
```

3. (מומלץ) התקינו ffmpeg כדי לקבל קובצי MP3 קטנים. בלי ffmpeg הקבצים יישמרו כ-WAV, שגדולים פי 10 בערך, ו-WAV לא עולה ל-git (הוא ב-.gitignore).
   - Windows: `winget install ffmpeg`
   - Mac: `brew install ffmpeg`

## 2. מפתח API

1. היכנסו ל-Google AI Studio וצרו מפתח API (Get API key).
2. הגדירו אותו בטרמינל לפני שמריצים את הסקריפט:
   - Windows (PowerShell): `$env:GEMINI_API_KEY="המפתח-שלכם"`
   - Mac: `export GEMINI_API_KEY="המפתח-שלכם"`

**חשוב:** אל תכתבו את המפתח בתוך הקוד ואל תעלו אותו לאתר או ל-GitHub. מי שמחזיק במפתח יכול להשתמש בו על חשבונכם.
קובץ `.env` נמצא ב-.gitignore, אבל הסקריפט לא קורא אותו: המפתח נקרא רק ממשתנה הסביבה.

## 3. יצירת הפרקים

פתחו את הטרמינל בתיקייה `tools/podcast` והריצו:

```
cd tools/podcast
python3 make_podcast.py --list
```

כך תראו את 22 תתי-הפרקים. התחילו בפרק אחד לבדיקה:

```
python3 make_podcast.py --only 1א
```

הקשיבו ל-`public/podcast/episodes/ep-1a.mp3`, או פשוט הריצו את האתר (`npm run dev`) ופתחו את עמוד הפודקאסט.
אם הקולות וההגייה בסדר, צרו את כל השאר:

```
python3 make_podcast.py
```

- פרקים שכבר נוצרו לא נוצרים שוב. אם הריצה נעצרה באמצע, פשוט הריצו שוב והיא תמשיך מאותו מקום.
- כדי ליצור פרק מחדש: `python3 make_podcast.py --only 1א --force`
- כל תת-פרק נשלח בקטעים של כשתי דקות, כי בקטעים ארוכים איכות ההקראה יורדת.
- `python3 make_podcast.py --captions` יוצר מחדש רק את הכתוביות, לפרקים שהאודיו שלהם כבר קיים. לא צריך מפתח API.

## 4. כתוביות

הכתוביות הן שורה לכל משפט, עם הזמן שבו הוא מתחיל. Gemini לא מחזיר זמנים, ולכן הסקריפט מוצא את
רגעי השקט באודיו ומשבץ בהם את גבולות המשפטים. הדיוק טוב ברוב המקרים, אבל לא מושלם: אם שורה נדלקת
מוקדם או מאוחר בכמה עשיריות שנייה, זה צפוי. באתר אפשר ללחוץ על שורה כדי לקפוץ אליה.

## 5. שינוי קולות

בראש `make_podcast.py` יש שתי שורות:

```
VOICE_YAEL = "Sulafat"
VOICE_OMER = "Puck"
```

קולות נשיים נוספים: Kore, Zephyr, Vindemiatrix, Aoede. קולות גבריים: Charon, Umbriel, Zubenelgenubi. אחרי שינוי קול, צרו את הפרקים מחדש עם `--force`.

## 6. העלאה לאתר

הקבצים כבר במקום הנכון. נשאר רק לשמור אותם ב-git ולדחוף:

```
git add public/podcast/episodes
git commit -m "Add podcast episodes"
git push
```

האתר נבנה ומתפרסם לבד. כל 22 הפרקים יחד שוקלים כ-75MB, וזה בסדר למגבלות של GitHub Pages
(אתר עד 1GB, קובץ עד 100MB). כדאי ליצור מחדש רק פרקים שבאמת השתנו, כי כל גרסה של קובץ אודיו נשארת
בהיסטוריה של git לתמיד.

## אם משהו לא עובד

- **"לא נמצא מפתח API"**: הגדירו את GEMINI_API_KEY באותו חלון טרמינל שבו אתם מריצים.
- **המודל לא זמין**: בדקו ב-Google AI Studio מה השם העדכני של מודל ההקראה (TTS), ועדכנו את הרשימה `MODELS` בראש הסקריפט.
- **שגיאת מכסה (429)**: הסקריפט מחכה ומנסה שוב לבד. אם זה ממשיך, הריצו שוב מאוחר יותר.
- **ההגייה בעברית לא מושלמת**: התמיכה בעברית בהקראה של Gemini עדיין בשלב preview. אפשר לנסות קול אחר.
- **"אין כלי לפענוח האודיו"** (רק עם `--captions`): לכתוביות מקובץ MP3 קיים צריך ffmpeg, או afconvert שמגיע עם Mac.
